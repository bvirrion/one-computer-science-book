$ python tcp_states.py
client  open as client   -> SYN-SENT      send SYN
client  receive SYN+ACK  -> ESTABLISHED   send ACK
server  open as server   -> LISTEN
server  receive SYN      -> SYN-RECEIVED  send SYN+ACK
server  receive ACK      -> ESTABLISHED
the client closes first:
client  close            -> FIN-WAIT-1    send FIN
client  receive ACK      -> FIN-WAIT-2
client  receive FIN      -> TIME-WAIT     send ACK
client  2 MSL pass       -> CLOSED
server  receive FIN      -> CLOSE-WAIT    send ACK
server  close            -> LAST-ACK      send FIN
server  receive ACK      -> CLOSED
